# CORPUS SEMILLA — composiciones humanas verbatim
#
# Este archivo es la ÚNICA fuente de vocabulario de la biblioteca. Todo carácter que
# la skill puede usar entra por aquí, porque un humano lo escribió en una composición
# real. `tools/construir-datos.mjs` lo decompone y genera skills/ua/data/*.json.
#
# NUNCA edites este archivo a mano para "añadir un símbolo suelto". El vocabulario
# crece pegando composiciones completas (por `/ua aprender`), no listando glifos: es
# la propiedad que impide que la biblioteca degenere en la lista plana que hace que
# las decoraciones generadas por IA se noten.
#

#   === <id> | <perfil> | <paleta> | <nota>
#   ...líneas de la composición, verbatim, incluidos espacios...
